# 剪切清单

JSON 使用原片时间，单位是秒。keep 是所有要保留的片段；**没有列入 keep 的时间将被删除**。每个片段必须有保留理由，必须按原片顺序排列，不能重叠或超过原片时长。相邻且无需切开的片段应合并。

```json
{
  "keep": [
    {"start": 4.2, "end": 10.8, "reason": "同一意思第三遍完整，替代前两次口误"},
    {"start": 13.1, "end": 20.4, "reason": "保留下一完整观点及有意强调"}
  ],
  "needs_review": []
}
```

若有疑点，先把文字说明放在 needs_review 中；校验器会阻止生成可执行清单和渲染，直到取舍明确。不要为了通过校验直接清空疑点。

Agent 另写 review.md，列出每处删除区间的原话、删除理由、替代它的保留片段。上面的数字只是格式示例，不能用在真实视频中。

`plan` 命令不会修改文件，打印预计时长、原片到成片的时间映射、删除区间与清单哈希。`render` 要求同一份文件的哈希；改动空格也会改变哈希，需要重新运行 plan。

时间戳必须根据原片转写与核听确定。句级 SRT 边界不适合直接切到半句话中间；先核听再确定切点。渲染按视频帧量化，因此实际时长允许少量帧级误差。
