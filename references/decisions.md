# 中文口播取舍示例

以下为原创合成文本，不是真实客户素材。省略号表示说话中断，不代表可自动删除的静音时长。Agent 应核听原片后确定切点。

| 情形 | 连续尝试 | 正确处理 |
| --- | --- | --- |
| 重说三遍 | “今天讲三个……”“今天讲两个技巧。”“今天讲三个选题技巧。” | 第三遍完整且修正了数字，保留第三遍 |
| 最后一遍放弃 | “先确定读者，再写标题。”“先确定……算了。” | 保留第一遍完整表达，删除第二遍重录 |
| 有意强调 | “先做出来，先做出来，再去优化。” | 保留整句；重复承担强调作用 |
| 开头相同但信息不同 | “这个方法适合新手。”“这个方法也适合小团队。” | 两句都保留，不能按文本相似度去重 |
| 重录增加信息 | “每天复盘。”“每天复盘，并保留原始记录。” | 后句完整替代前句，保留后句 |
| 口令夹在中间 | “重新来一遍。今天我们讨论素材归档。” | 删除重录口令，保留后面的正式句子 |
| 模糊修改 | “成本是五百。”“不对，大概……” | 不推测最终数字，列为待确认 |
| 自然停顿 | “做内容最重要的——是持续观察。” | 保留表达节奏，不能按静音阈值自动剪掉 |

检查一个替代关系时，读完整上下文。保留的版本应包含被删版本的必要信息；若包含两个不同观点，就不能当作同一组重拍。

建议首次验收用三段自有短视频：正常重说、末遍不完整、修辞重复。分别检查保留版本、语义覆盖与接缝听感。合成测试只验证渲染机械行为，不能代替中文语义验收。
